                  Работа с записью

                  журнал сохраняется в браузере

                  Файл воспроизводится тем же разбором, что и живой поток: годятся выгрузки этого пульта и CSV-файлы эмулятора.

                  Подключение

                  —

                  Эмулятор телеметрии: python emulator.py → GET /telemetry

                  Эмулятор отдаёт только последний кадр, поэтому опрос должен быть чаще интервала кадров. Пульт подбирает интервал сам по измеренной полноте потока; чтобы задать вручную, измените поле и нажмите «Сохранить настройки».

                  После этой паузы показания помечаются как устаревшие.

                  Пороги состояний

                  напряжение батареи, В

                  Значения по умолчанию соответствуют комплекту учебного пульта: 7,2–8,5 В — рабочий диапазон, 6,6 и 8,7 В — границы аварии. Авария имеет приоритет над вниманием.

                  Отображение

                  —

                  Переносит список модулей вместе с показаниями. Слева он виден на всех экранах, справа — только в «Обзоре», зато графики становятся шире.

                  Данные

                  —

                  Журнал пакетов, настройки и прошлая сессия хранятся в браузере (localStorage). Данные никуда не отправляются.

                  Справка оператора

                  Первый запуск

                  1. Установите Python 3.10+ и запустите эмулятор в его папке: python emulator.py
                  2. Выберите файл телеметрии (для проверки — 01_normal_flight.csv)
                  3. В окне появится адрес http://127.0.0.1:8765/telemetry — пульт подхватит его сам

                  Горячие клавиши

                  • 1…6переключение экранов
                  • Pзаморозить / возобновить приём
                  • Gследующая группа графика
                  • Lпоказать или скрыть легенду графика
                  • ?эта справка
                  • Escзакрыть окно

                  Цвета состояний

                  • норма — показания в допуске
                  • внимание — данные есть, но требуют проверки
                  • авария — модуль недоступен или параметр вне допуска
